导言 · 从战争到战略

军事思想（military thought）是人类对战争与暴力的系统思考——它既包括如何打赢战争（战略与战术），也包括如何看待战争（战争观），还包括如何避免战争（威慑与和平）。军事思想史追问四个根本问题：战争从哪里来（起源论）、战争有无规律（规律论）、战争为谁而战（价值论）、战争如何结束与避免（和平论）。它不教人"好战"，而是回答"人类为何战争、又如何驾驭战争"。

一条主线 军事思想的主线，是"战争为谁而战"的几次转向：为生存（部落冲突：争夺生存资源）→ 为权力（帝国征服：争夺领土霸权）→ 为信仰（宗教战争：圣战与十字军）→ 为国家（民族国家：主权与民族战争）→ 为意识形态（冷战：主义之争与代理人战争）→ 为算法（AI 时代：信息战与认知战）。每一次转向，都是人类重新回答"战争是毁灭还是工具、是艺术还是科学"。

本辑以军事思想自身的演变为线索——中国古代兵家（道胜于术）、西方古典与近代（战争是政治的延续）、现代战争（总体战与核威慑）、人民战争（民心为本）、当代前沿（信息战与 AI 战争），看人类如何从"杀伐之术"走向"战略之道"，再走向"和平之学"。

第一章总览：军事思想的演变

先看全景：人类从部落冲突中学会组织，从冷兵器时代走向火器时代，从线式战术走向机械化战争，从核威慑走向信息战与 AI 战争。东方以《孙子兵法》"不战而屈人之兵"为最高境界，西方以克劳塞维茨"战争是政治的延续"为经典定义。军事思想从"术"（战术技巧）走向"道"（战略哲学），再走向"学"（军事科学）——它既是杀伐之术，也是治国之道，更是和平之学。

历史背景

中国军事传统：孙子著《孙子兵法》"兵者，国之大事"；吴起、孙膑发展先秦兵家；曹操注《孙子》；戚继光《纪效新书》抗倭练兵；毛泽东军事思想把战争升华为"人民战争"——从"兵者诡道"到"兵民是胜利之本"。

西方军事传统：修昔底德《伯罗奔尼撒战争史》分析战争根源；马基雅维利《君主论》论战争与政治；克劳塞维茨《战争论》"战争是政治的延续"；约米尼《战争艺术概论》把战争当作科学；马汉《海权论》、杜黑《制空权》开辟海权与空权时代。

军事思想的转向：从"歼灭战"到"威慑战"，从"消耗战"到"信息战"，从"人海战术"到"无人化战争"——技术不断改变战争形态，而思想决定战争的方向。军事思想始终回答同一个问题：人类如何用最小的代价赢得战争、又如何避免战争。

孙子（约前 545–前 470）——兵圣。《孙子兵法》"不战而屈人之兵"。

马基雅维利（1469–1527）——近代政治军事之父。《君主论》论战争。

核心法则

不战而屈人之兵 最高胜利 = 不战 + 屈人之兵（孙子） 孙子把"不战而胜"置于"百战百胜"之上——军事的最高境界不是毁灭，而是以谋略与威慑达成目标。
战争是政治的延续 战争 = 政治（以其他手段的继续）（克劳塞维茨） 克劳塞维茨把战争从"暴力游戏"提升为"政治工具"——战争服务于政治目的，政治决定战争的方向与限度。
战争是科学的艺术 军事 = 科学（规律）+ 艺术（天才） 约米尼主张战争有规律可循、可教可学；但克劳塞维茨强调战争充满摩擦与偶然，需要天才的直觉——二者互补。
威慑与平衡 和平 = 威慑（让对方不敢打）+ 平衡（均势） 从均势外交到核威慑，军事思想最终指向"以战止战"——让战争的成本高到无人敢于发动。

第二章中国古代军事思想：从孙子到戚继光

定义：中国古代军事思想以《孙子兵法》为巅峰，涵盖先秦兵家（孙子、吴起、孙膑）、秦汉至唐宋的战争实践（韩信、曹操、李靖）、明清的军事总结（戚继光）。其核心是"道天地将法"的体系化思考，强调"不战而屈人之兵"的最高境界、"知己知彼"的认知原则、"以正合以奇胜"的战术智慧。它不仅是战争之术，更是治国与处世的哲学——"兵者，国之大事"。

历史背景

春秋战国（前 770–前 221）：礼崩乐坏，战争频繁，兵家兴起。《孙子兵法》成书于春秋末期，为兵学之祖。

战国兵家：吴起《吴子》"内修文德，外治武备"；孙膑"围魏救赵"、"减灶诱敌"。

秦汉：韩信"背水一战"、"十面埋伏"；曹操注《孙子》，"以法治军"。

唐宋：李靖《唐李问对》，"以正合以奇胜"；《武经七书》确立兵学经典。

明清：戚继光《纪效新书》《练兵实纪》抗倭，火器与阵法结合，练兵与练将并重。

代表人物

孙子（约前 545–前 470）——兵圣。《孙子兵法》十三篇，兵学之祖。

吴起（前 440–前 381）——兵家代表。与孙子并称"孙吴"。

孙膑（约前 380–前 320）——战国兵家。围魏救赵，兵法传世。

韩信（约前 231–前 196）——兵仙。暗度陈仓、背水一战。

曹操（155–220）——注《孙子》者。以法治军，唯才是举。

李靖（571–649）——大唐军神。灭东突厥，著《唐李问对》。

岳飞（1103–1142）——精忠报国。岳家军"冻死不拆屋，饿死不掳掠"。

戚继光（1528–1588）——抗倭名将。鸳鸯阵，练新军。

核心法则

五事七计 胜负 = 道 + 天 + 地 + 将 + 法 孙子以"道天地将法"五事评估战争：道义、天时、地利、将才、法度——道义（民心）居首。
知己知彼 知彼知己，百战不殆 认知是战争的第一要素——不了解敌我双方，再强的兵力也会陷入盲目。
以正合以奇胜 战术 = 正兵（正面牵制）+ 奇兵（出其不意） 韩信背水一战、孙膑围魏救赵，都是"以奇胜"的经典——奇正相生，变化无穷。
兵贵神速 用兵 = 速战速决 + 以逸待劳 "兵之情主速，乘人之不及"——时间与机动是冷兵器时代最稀缺的战略资源。

第三章西方古典与近代军事思想：从修昔底德到拿破仑

定义：西方军事思想从古希腊的战争分析出发，经罗马的军团制度、中世纪的骑士战争，到近代的常备军与拿破仑战争，最终由克劳塞维茨《战争论》与约米尼《战争艺术概论》完成理论化。其核心是"战争是政治的延续"（克劳塞维茨）与"战争是科学的艺术"（约米尼），强调集中兵力、内线作战、歼灭敌军主力——西方军事思想由此从"经验"走向"理论"。

历史背景

古希腊（前 5 世纪）：希波战争、伯罗奔尼撒战争；修昔底德分析战争根源——恐惧、荣誉、利益。

罗马（前 3 世纪–5 世纪）：军团制度、职业化军队，"条条大路通罗马"的军事后勤与工程能力。

中世纪（5–15 世纪）：骑士战争、城堡攻防、十字军东征；火药传入改变战争形态。

近代（16–18 世纪）：三十年战争、常备军兴起；腓特烈大帝的斜线战术；马基雅维利《君主论》论战争与政治。

拿破仑战争（1803–1815）：拿破仑以机动、集中、歼灭战横扫欧洲，成为军事天才的巅峰。

理论化（19 世纪）：克劳塞维茨《战争论》（1832）、约米尼《战争艺术概论》（1838）——西方军事科学诞生。

代表人物

修昔底德（约前 460–前 400）——战争分析之父。恐惧、荣誉、利益三因。

亚历山大（前 356–前 323）——马其顿征服者。以少胜多，东征至印度。

凯撒（前 100–前 44）——罗马统帅。"我来了，我看见了，我征服了"。

马基雅维利（1469–1527）——近代政治军事之父。《君主论》《战争的艺术》。

腓特烈大帝（1712–1786）——普鲁士军事改革者。斜线战术。

拿破仑（1769–1821）——军事天才。机动、集中、歼灭战。

克劳塞维茨（1780–1831）——战争哲学大师。《战争论》。

约米尼（1779–1869）——战争科学论者。《战争艺术概论》。

核心法则

战争三因（修昔底德） 战争根源 = 恐惧 + 荣誉 + 利益 修昔底德最早系统分析战争根源——恐惧（安全困境）、荣誉（尊严）、利益（资源），至今仍是国际关系分析的经典框架。
战争是政治的延续 战争 = 政治 + 暴力（克劳塞维茨） 克劳塞维茨强调战争服务于政治目的，受政治制约——"战争不是盲目的激情，而是理智的运用"。
集中兵力 胜利 = 在决定点集中优势兵力 拿破仑的机动与集中、克劳塞维茨的"重心"理论——在关键地点形成局部优势，是西方军事的核心法则。
歼灭战 目标 = 消灭敌军主力 + 摧毁其抵抗意志 与东方"不战而胜"不同，西方古典军事以"歼灭敌军主力"为直接目标——决战决定胜负。

第四章现代战争思想：从总体战到核威慑

定义：现代战争思想诞生于工业革命与两次世界大战——战争从"军队对军队"扩展为"国家对国家"的总体战，从陆地扩展到海洋与天空，最终进入核威慑时代。其核心命题是：技术如何改变战争形态（海权、空权、装甲战、核威慑），以及人类如何在毁灭性武器面前避免战争（威慑理论、军备控制）。现代军事思想由此从"如何打赢战争"转向"如何避免毁灭"。

历史背景

工业革命（19 世纪）：铁路、电报、机枪、毒气改变战争——后勤与火力革命。

海权论（1890）：马汉《海权对历史的影响》——控制海洋即控制世界。

制空权（1921）：杜黑《制空权》——空军决定战争胜负。

一战（1914–1918）：堑壕战、总体战雏形；鲁登道夫《总体战》提出全民动员。

二战（1939–1945）：闪电战（古德里安）、装甲战、战略轰炸、原子弹——战争进入核时代。

冷战（1947–1991）：核威慑、相互确保摧毁（MAD）、军备控制——"以核止核"。

核心法则

海权论（马汉） 大国兴衰 = 制海权（海军 + 商船 + 基地） 马汉论证：谁控制海洋，谁就控制贸易与财富——海权决定大国命运，深刻影响美国、日本的海军战略。
制空权（杜黑） 制空权 = 胜利的关键 杜黑预言空军将独立决定战争胜负——战略轰炸、夺取制空权成为现代战争的首要目标。
总体战（鲁登道夫） 战争 = 全民 + 全资源 + 全领域 鲁登道夫把战争从"军队的事"扩展为"全民的事"——经济、工业、宣传都成为战场。
核威慑（MAD） 和平 = 相互确保摧毁（让对方不敢先动手） 核武器的毁灭性使"打赢战争"失去意义——威慑取代实战，军备控制成为大国博弈的常态。

第五章东方战争智慧与人民战争：从《孙子兵法》到毛泽东军事思想

定义：东方战争智慧以《孙子兵法》为源头，在近现代由毛泽东军事思想推向新高度。其核心是"人民战争"——战争不仅是军队的对抗，更是政治、经济、人心的全面较量；"农村包围城市"的革命道路、"敌进我退，敌驻我扰，敌疲我打，敌退我追"的游击战十六字诀、"兵民是胜利之本"的群众路线。它把战争从"将帅的艺术"变成"人民的战争"，是东方智慧在现代的创造性转化。

历史背景

近代冲击（1840–1911）：鸦片战争、甲午战争，传统军事思想面对西方军事技术的冲击。

土地革命（1927–1937）：红军创建，游击战十六字诀，"农村包围城市"道路确立。

抗日战争（1937–1945）：《论持久战》战略指导，敌后游击战与人民战争。

解放战争（1946–1949）：运动战、歼灭战，三大战役以少胜多。

抗美援朝（1950–1953）：人民战争与现代化战争的结合，以弱胜强。

代表人物

核心法则

人民战争 战争 = 人民（政治动员）+ 军队（武装斗争） 毛泽东把战争从"军队的事"变为"人民的事"——"战争的伟力之最深厚的根源，存在于民众之中"。
农村包围城市 革命道路 = 农村根据地 + 武装斗争 + 土地革命 在半殖民地半封建的中国，走"农村包围城市、武装夺取政权"的道路——这是中国革命的独特路径。
游击战十六字诀 敌进我退 · 敌驻我扰 · 敌疲我打 · 敌退我追 以弱对强的战术智慧——不与敌人拼消耗，而是调动敌人、寻找战机、积小胜为大胜。
论持久战 抗战 = 战略防御 → 战略相持 → 战略反攻 《论持久战》科学预判战争三阶段，批驳"亡国论"与"速胜论"——战略耐心与全局眼光。

第六章当代军事与战略前沿：信息战、AI 战争与混合战争

定义：当代军事思想面对信息化与智能化革命——战争形态从"平台中心战"转向"网络中心战"，从"火力制胜"转向"信息制胜"，从"有人战争"转向"无人战争"。核心命题包括：信息战与认知战（争夺人心与认知）、AI 战争（自主武器系统）、太空战与网络战、混合战争（常规+非常规+信息+经济）、以及无人化与智能化战争带来的伦理与治理问题。军事思想由此进入"算法与人心"的新战场。

历史背景

海湾战争（1991）：信息化战争雏形，"外科手术式打击"，精确制导改变战争。

网络战：网络攻击成为第五战场——瘫痪电网、金融、指挥系统。

无人机战争：反恐战争中的无人机打击，战争进入"无人化"。

AI 军事化：自主武器系统、算法战、智能决策辅助。

混合战争（2014）：克里米亚事件——常规+信息+代理+经济战的混合形态。

核心法则

OODA 循环（博伊德） 制胜 = 观察 → 判断 → 决策 → 行动（快于对手） 博伊德提出：在信息时代，谁能在更短的循环内完成"观察-判断-决策-行动"，谁就掌握战场主动权。
网络中心战 战斗力 = 信息优势 + 网络连接 + 精确打击 从"平台中心"转向"网络中心"——信息共享使分散的部队形成整体战斗力。
认知战 新战场 = 人心 + 认知 + 信息 当代战争不仅争夺领土，更争夺认知——假信息、算法操纵、舆论战成为"认知域"武器。
混合战争 战争 = 常规 + 非常规 + 信息 + 经济 + 代理 霍夫曼提出"混合威胁"——对手同时使用正规军、游击队、网络攻击、经济施压与信息战，模糊战争与和平的界限。

第七章总结提炼：军事思想的启示

回顾从孙子到 AI 战争，可以提炼出军事思想的核心规律：道胜于术、不战而胜、民心为本、技术变革、威慑和平。战争不是目的，而是政治的工具；最好的胜利是不战而胜；人民是战争胜负的根本；技术不断改变战争形态，但战争的本质——政治与人心——不变；核威慑与军备控制证明，人类有能力避免自我毁灭。

五大规律的提炼

道胜于术：军事的最高境界不是蛮力，而是谋略与道义。孙子"不战而屈人之兵"、克劳塞维茨"战争是政治的延续"——道义、政治、谋略高于单纯的武力。

不战而胜：最好的胜利是避免战争。从孙子"上兵伐谋"到核威慑时代的"以核止核"——军事思想最终指向"以战止战"。

民心为本：人民是战争胜负的根本。刘邦得民心得天下，毛泽东"兵民是胜利之本"——民心向背决定战争走向。

技术变革：技术不断改变战争形态。从冷兵器到火器、从海权到空权、从机械化到信息化、从有人到无人——技术改变战争，但战争的本质不变。

威慑和平：人类有能力避免自我毁灭。核威慑、军备控制、国际法——军事思想的最终价值，是让战争的成本高到无人敢于发动，让和平成为理性的选择。
