导言 · "社会"的发现

社会思想（social thought）是人类对"社会"这一独特存在物的系统反思——在漫长的历史中，人们只看到君主、神祇、家族与个人，却看不见"社会"本身。直到工业革命的巨浪打碎了传统共同体，"社会"才作为一个独立的研究对象被发现：它不由任何人设计，却支配着每个人；它无形无相，却比任何实体都更坚固。社会思想史追问四个根本问题：社会是什么（本体论）、社会如何可能（秩序论）、个人与社会何者优先（方法论）、现代社会向何处去（现代性论）。

一条主线 社会思想的主线，是"社会如何被看见"的几次转向：为神（传统社会：秩序来自神意与礼法，社会不被追问）→ 为科学（孔德、斯宾塞：社会像自然一样有规律）→ 为秩序（涂尔干：社会是外在于个人的"社会事实"）→ 为意义（韦伯：社会行动背后的主观意义）→ 为批判（马克思：社会关系中的压迫与解放）→ 为反思（当代：风险社会、流动现代性中的自我追问）。每一次转向，都是人类重新回答"我们身处的这个巨大而无形之物，究竟是什么"。

本辑沿社会思想自身的谱系展开——奠基时代（孔德、斯宾塞、涂尔干）、解释与批判（韦伯、马克思）、现代社会理论（功能主义、符号互动、冲突理论）、当代前沿（布迪厄、吉登斯、哈贝马斯、鲍曼、贝克），看"社会"如何从神意的阴影中走出，成为人类理解自身的核心透镜。它与第七辑（经济）、第十一辑（法哲学）共同构成"现代社会三大支柱"的思想图谱。

第一章总览：社会思想的演变

先看全景：在孔德发明"社会学"（sociologie）一词之前，人类并非没有社会思想——柏拉图的《理想国》、亚里士多德"人是政治动物"、荀子"人能群"、马基雅维利、霍布斯、孟德斯鸠、卢梭都在思考秩序与共同体。但那是"政治哲学"而非"社会思想"——它追问"应当如何统治"，而非"社会实际如何运转"。工业革命把一切彻底改变了：传统的共同体瓦解，阶级冲突剧烈，城市人口爆炸，旧的所有解释都失灵了。正是在这片废墟上，社会学作为一门独立学科诞生：孔德要"用物理学的方法研究社会"，涂尔干要"把社会事实当作物来考察"，韦伯要"理解行动的主观意义"，马克思要"揭示生产关系中的支配结构"。

历史背景

前社会学时代：柏拉图《理想国》的等级秩序、亚里士多德"人是政治动物"、荀子"人生不能无群"、霍布斯《利维坦》的自然状态、卢梭的社会契约、孟德斯鸠《论法的精神》的风俗与社会类型——社会思想在政治哲学中孕育。

社会学的诞生（1830s–1900）：工业革命与法国大革命的双重震荡催生社会学。孔德命名"社会学"并提出实证主义；斯宾塞以生物类比建立"社会有机体论"；涂尔干确立学科规范（《社会学方法的规则》），创办第一个社会学系；滕尼斯区分"共同体与社会"；齐美尔开创形式社会学。

经典三大家（1890–1920）：涂尔干（社会秩序）、韦伯（社会行动与理性化）、马克思（阶级与批判）——三大传统至今仍是社会理论的基本坐标。

美国社会学与功能主义（1920–1960）：芝加哥学派的城市研究；帕森斯的结构功能主义一统天下；默顿的中层理论；符号互动论（米德、戈夫曼）另辟蹊径。

冲突与反思（1960–）：达伦多夫的冲突理论挑战功能主义；布迪厄、吉登斯、哈贝马斯重建社会理论；鲍曼、贝克诊断"流动的现代性"与"风险社会"——社会思想进入反思时代。

核心法则

社会事实（涂尔干） 社会事实 = 外在性 + 强制性 + 普遍性 法律、道德、语言、货币——它们先于个人而存在、约束个人行动，"把社会事实当作物来考察"是社会学的起点。
理想类型（韦伯） 理想类型 = 提炼特征 + 衡量现实的思想工具 韦伯的方法论：从现实中提炼纯粹形态（如"科层制"），再用它衡量现实偏离多远——不是描述，而是分析工具。
结构二重性（吉登斯） 结构 ⇄ 行动：结构既制约行动，又被行动再生产 社会结构与个人行动不是谁先谁后——我们在结构中行动，行动又不断重塑结构，如语法与言语的关系。
反思性现代化（贝克/吉登斯） 第二现代性 = 现代性开始反思自身制造的后果 工业社会解决稀缺问题，风险社会面对自己制造的风险——核、生态、基因，现代性开始反噬自身。

第二章奠基时代：孔德、斯宾塞与涂尔干

定义：社会学的奠基时代（1830–1920）回答第一个问题——"社会是什么、社会如何可能"。孔德命名社会学并主张以实证方法研究"社会秩序与社会进步"；斯宾塞把社会比作生物有机体，提出从军事社会到工业社会的进化；涂尔干则以《社会分工论》《自杀论》《宗教生活的基本形式》确立学科典范：社会不是个人的简单相加，而是有自己的规律、自己的力量的"社会事实"。这个时代的关键词是：实证、有机体、分工、失范、集体表象。

历史背景

大革命后的法国：孔德亲历革命后的秩序危机，提出"以爱为原则、以秩序为基础、以进步为目的"，用社会学重建社会共识。

工业革命的英国：斯宾塞见证工业社会的兴起，将社会进化类比为生物进化——从同质到异质、从简单到复杂；他主张自由放任，认为干预会破坏自然进程。

第三共和国危机：涂尔干面对德雷福斯事件与社会失序，追问"现代分工社会靠什么团结"——他的答案：从"机械团结"（相似性）转向"有机团结"（相互依赖）。

《自杀论》（1897）：社会学方法的典范之作——连自杀这样最私人的行为，其比率也受社会整合程度支配，证明"社会事实"的独立实在性。

代表人物

孔德（1798–1857）——社会学之父。三阶段定律：神学→形而上学→实证。

斯宾塞（1820–1903）——社会达尔文主义者（先于达尔文使用"适者生存"）。

涂尔干（1858–1917）——学科制度建立者。法国第一位社会学教授。

滕尼斯（1855–1936）——《共同体与社会》（1887）。礼俗社会与法理社会。

齐美尔（1858–1918）——微观与形式社会学。大都会与货币精神生活。

核心法则

三阶段定律（孔德） 人类思想 = 神学阶段 → 形而上学阶段 → 实证阶段 从神的意志到抽象概念再到科学规律——孔德认为社会学是"科学的皇后"，是实证阶段的最高成就。
机械团结 → 有机团结（涂尔干） 传统社会：相似性团结（压制性法律）→ 现代社会：分工团结（恢复性法律） 分工不只是经济现象，更是道德现象——现代社会靠相互依赖而非彼此相似而团结。
失范（anomie） 失范 = 社会规范失效 + 欲望失去节制 当旧规范瓦解而新规范未立，个人陷入无节制的欲望与迷茫——失范型自杀是社会整合失败的标志。
共同体与社会（滕尼斯） 共同体 = 本质意志（血缘·地缘·精神）；社会 = 选择意志（契约·利益·理性） 现代化就是"从共同体到社会"——乡村温情让位于城市契约，这是所有社会诊断的原型结构。

第三章解释与批判：韦伯与马克思

定义：如果说涂尔干代表"秩序"传统，韦伯与马克思则分别代表另外两大传统——解释与批判。韦伯追问：社会行动背后有什么主观意义？他由此发现西方现代性的核心进程是"理性化"——世界的祛魅、科层制的扩张、以及令人窒息的"铁笼"。马克思追问：社会关系掩盖了怎样的支配？他揭示生产关系中的剥削、异化与意识形态，并把思想本身放回它的社会位置（社会存在决定社会意识）。一个解释意义，一个揭露支配——他们共同把社会思想从"描述"推向"诊断与批判"。

历史背景

德意志帝国时期：韦伯目睹德国快速的工业化与官僚化，既惊叹于资本主义的效率，又忧虑理性化的代价——意义与自由的丧失。

《新教伦理》（1904–1905）：韦伯论证新教禁欲伦理与资本主义精神的"选择性亲和"——观念也能成为历史的动力，与唯物论展开对话。

工业资本主义的苦难：马克思在曼彻斯特的工厂中看到工人阶级的处境，写下《1844 年经济学哲学手稿》（异化劳动）与《资本论》（剩余价值）。

两条道路的分歧：韦伯强调观念、地位与权力的多元维度；马克思强调生产方式与阶级的根本地位——这场对话贯穿了整个 20 世纪社会科学。

代表人物

马克斯·韦伯（1864–1920）——理解社会学之父。理性化、三种支配类型、科层制。

卡尔·马克思（1818–1883）——批判传统的源头。历史唯物论、阶级、异化、意识形态。

恩格斯（1820–1895）——合作者与独立思想家。《英国工人阶级状况》。

卢卡奇（1885–1971）——物化理论。把异化扩展为整个社会的物化意识。

葛兰西（1891–1937）——文化领导权（hegemony）。统治靠同意而非仅靠强制。

马尔库塞（1898–1979）——法兰克福学派。《单向度的人》批判发达工业社会。

核心法则

四种社会行动（韦伯） 行动 = 工具理性 + 价值理性 + 情感 + 传统 韦伯分类社会行动的四种取向——现代化就是工具理性压倒价值理性的过程。
理性化铁笼（韦伯） 铁笼 = 科层制 + 计算精神 + 祛魅 理性组织带来效率，也带来囚禁——"专家没有灵魂，纵欲者没有心肝"，现代人困在自己制造的理性铁笼中。
异化劳动（马克思） 异化 = 与产品疏离 + 与过程疏离 + 与类本质疏离 + 与他人疏离 工人生产得越多，自己越是贫瘠；劳动本是人的本质，却成为外在的苦役——异化是资本主义最深的精神创伤。
文化领导权（葛兰西） 统治 = 强制（国家机器）+ 同意（文化领导权） 支配者不仅靠暴力统治，更靠把自身利益塑造为"普遍常识"来获得被统治者的自愿同意。

第四章现代社会理论：功能、互动与冲突

定义：二战后的美国，社会学迎来制度化的黄金时代，三大范式鼎立。结构功能主义（帕森斯、默顿）把社会看作相互调适的系统，追问"各部分如何维持整体秩序"；符号互动论（米德、布鲁默、戈夫曼）转向微观，追问"意义如何在互动中生成"——社会是由日常表演与符号交换构成的；冲突理论（达伦多夫、科塞、米尔斯）则反驳功能主义：社会不是和谐的系统，而是利益冲突的角斗场，秩序只是暂时压制冲突的结果。三大范式的争论，就是"秩序、意义、权力"三种视角的互补与竞争。

历史背景

战后美国（1945–1965）：社会学的重心从欧洲移到美国。帕森斯以《社会行动的结构》整合欧洲经典，建立结构功能主义的理论帝国；默顿以"中层理论"与功能分析把它推向经验研究。

芝加哥传统：从帕克的城市研究到米德的社会心理学，再到布鲁默命名"符号互动论"、戈夫曼的《日常生活中的自我呈现》——微观社会学开枝散叶。

六十年代反叛：越战、民权运动、学生运动打破了功能主义的和谐幻象。达伦多夫《工业社会中的阶级与阶级冲突》、米尔斯《权力精英》、科塞《社会冲突的功能》——冲突视角兴起，法兰克福学派西传。

范式竞争：库恩"范式"概念传入社会科学——三大范式长期并存，没有哪一种能独霸，社会实在本就允许多重透镜。

代表人物

帕森斯（1902–1979）——结构功能主义集大成者。AGIL 四功能模式。

默顿（1910–2003）——中层理论。显功能/潜功能、自我实现预言。

米德（1863–1931）——符号互动论源头。主我/客我、概化他人。

米尔斯（1916–1962）——《权力精英》。"社会学的想象力"。

科塞（1913–2003）——冲突功能论者。冲突也能促进整合。

核心法则

AGIL 模式（帕森斯） 任何社会系统 = 适应(A) + 目标达成(G) + 整合(I) + 模式维持(L) 帕森斯认为一切行动系统都必须完成四项功能——经济适应环境、政治达成目标、社会整合成员、文化维持价值。
自我实现预言（默顿） 预言 → 行为改变 → 预言成真 最初对情境的错误定义，引发新的行为，使原本错误的观念变成现实——银行挤兑、标签效应皆是如此。
拟剧论（戈夫曼） 社会生活 = 前台表演 + 后台卸妆 + 印象管理 人人都在"表演"自我——前台按剧本呈现理想形象，后台才得以放松；社会互动即舞台艺术。
社会学的想象力（米尔斯） 个人困扰 ⇄ 公共议题 把"个人传记"与"历史结构"联系起来——失业不只是个人无能，而是经济结构的产物，这就是社会学的心智品质。

第五章当代社会理论：从场域到风险社会

定义：1970 年代以来，社会理论进入"反思与综合"的时代。布迪厄用"场域—惯习—资本"消解客观主义与主观主义的对立；吉登斯以"结构化理论"弥合结构与行动的鸿沟；哈贝马斯以"交往理性"对抗工具理性的殖民；鲍曼宣告"流动的现代性"——一切坚固的东西不仅烟消云散，而且不再凝固；贝克诊断"风险社会"——现代性的主要矛盾从财富分配转向风险分配。共同的主题是：现代性开始反思它自己。

历史背景

68 之后：五月风暴的失败使知识分子重新思考结构——布迪厄揭示教育与文化再生产如何让不平等"被误识"为天赋差异。

晚期资本主义：哈贝马斯诊断"生活世界被系统殖民"——经济与行政逻辑侵入家庭、文化、人际领域；出路在未被扭曲的"交往理性"。

苏东剧变与全球化（1989–）：吉登斯提出结构化理论与"第三条道路"；鲍曼以"流动的现代性"描述后福特主义时代的不确定人生。

切尔诺贝利（1986）：贝克《风险社会》同年问世——核尘埃不认国界，风险的分配逻辑开始取代财富的分配逻辑，"有组织的不负责任"成为制度性困境。

数字时代：福柯的规训理论与"全景敞视"在算法监控时代重获新生——监控资本主义、平台社会成为新议程。

布迪厄（1930–2002）——场域理论。惯习、文化资本、符号暴力。

核心法则

实践的逻辑（布迪厄） 实践 = 惯习 × 资本 + 场域 行动既非机械服从结构，也非自由意志的产物——惯习（内化的结构）在特定场域中、凭手中资本展开游戏。
符号暴力（布迪厄） 符号暴力 = 被误识为正当的支配 最深刻的支配不需要武力——当被支配者把支配秩序当作"天经地义"接受时，符号暴力就成功了。
系统对生活世界的殖民（哈贝马斯） 危机 = 系统（金钱·权力）侵入生活世界（文化·社会·人格） 当以沟通为媒介的生活领域被金钱与行政命令的逻辑接管，意义危机与合法性危机就爆发了。
风险社会（贝克） 第一现代性：分配财富（稀缺）；第二现代性：分配风险（自造） "贫困是等级制的，烟雾是民主的"——风险面前人人平等，且风险由现代化自身制造，形成"有组织的不负责任"。
规训与全景敞视（福柯） 现代权力 = 监视 + 规范化 + 自我审查 圆形监狱的囚犯因"可能被看见"而自我约束——现代权力不靠血腥展示，而靠让每个人成为自己的狱卒。

第六章总结提炼：社会思想的启示

回顾从孔德到风险社会的近两百年，可以提炼出社会思想的核心规律：社会先于个人、秩序与变迁、理性化与异化、结构与能动、风险与反思。"社会"是一个奇怪的存在——它由每个人构成，却不等于任何个人；它被我们的行动不断再生产，却反过来塑造我们的行动。社会思想的全部努力，就是把这个无形之网变成可以看见、可以讨论、可以改造的对象。

五大规律的提炼

社会先于个人：语言、货币、法律、道德在我们出生前就已存在，并塑造我们的思想与行动——涂尔干的"社会事实"是社会学的第一块基石，也是对"孤立个人"幻象的永久解毒剂。

秩序与变迁：功能主义问"秩序何以可能"，冲突理论问"变迁从何而来"——秩序是冲突的暂时冻结，冲突是秩序的永恒潜流；两者合起来才是完整的社会动力学。

理性化与异化：韦伯的铁笼与马克思的异化是同一个现代性的两面——效率与计算带来前所未有的力量，也带来意义与自由的流失；任何进步叙事都必须经过这双重诊断的检验。

结构与能动：布迪厄与吉登斯告诉我们，结构不是牢笼也不是虚无——它通过惯习与惯例被行动再生产；改变行动就是改变结构，这正是社会实践的希望所在。

风险与反思：当现代性开始制造全球性、不可计算的风险，社会思想的任务从"建设现代性"转向"反思现代性"——学会与自己制造的后果共处，是第二现代性的核心课题。
