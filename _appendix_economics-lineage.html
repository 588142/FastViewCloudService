附录二精确定义与术语表

本术语表收录了经济思想史上篇中最核心的15个术语，每个术语均标注英文对应词、符号表示、严格定义以及常见的易混点辨析。

术语英文符号严格定义易混点辨析
稀缺性Scarcity—社会拥有的资源（土地、劳动、资本、企业家才能）永远无法满足人类无限的欲望，这一事实是经济学存在的根本前提。不同于"短缺"（shortage），短缺是价格低于均衡时的暂时现象；稀缺是永恒的，无法通过价格机制消除。
机会成本Opportunity CostOC为得到某物而放弃的最高价值替代方案的成本。机会成本不仅包括显性货币成本，还包括隐性成本（如放弃的时间价值）。不同于会计成本（仅计算实际支出）。机会成本是决策相关成本，是经济学思维的核心。
边际效用Marginal UtilityMU消费者从额外消费一单位商品中获得的满足感的增量。MU = dU/dQ，边际效用递减规律是需求曲线向右下倾斜的微观基础。不同于总效用（TU）。边际效用是总效用对消费量的导数，描述了"最后一单位"的效用。
需求价格弹性Price Elasticity of DemandEd需求量变化百分比与价格变化百分比之比：Ed = (dQ/Q)/(dP/P)。|Ed|>1为富有弹性，<1为缺乏弹性。不同于斜率。斜率取决于单位，弹性是无量纲的比率。直线需求曲线上各点弹性不同。
消费者剩余Consumer SurplusCS消费者愿意支付的最高价格与实际支付价格之间的差额。CS = ∫(需求曲线函数 - 价格) dQ，衡量消费者从交易中获得的净收益。不同于生产者剩余（PS）。CS + PS = 总剩余，衡量市场交易带来的社会福利。
生产者剩余Producer SurplusPS生产者实际收到的价格与其愿意接受的最低价格之间的差额。PS = ∫(价格 - 供给曲线函数) dQ。不同于利润。生产者剩余 = 收入 - 可变成本，而利润 = 收入 - 总成本（含固定成本）。
帕累托最优Pareto Optimum—一种资源配置状态，在不使任何人的状况变差的前提下，无法使任何人的状况变得更好。第一福利定理：完全竞争市场达到帕累托最优。不同于卡尔多-希克斯效率（允许补偿）。帕累托改进要求至少一人变好且无人变差。
外部性Externality—一个经济主体的行为对另一个主体的福利产生影响，但该影响未通过市场价格反映。负外部性（如污染）导致过度供给，正外部性（如教育）导致供给不足。不同于公共品。公共品具有非竞争性和非排他性，外部性不一定同时具备这两个特征。
劳动价值论Labor Theory of Value—商品的价值由生产该商品所耗费的社会必要劳动时间决定。古典经济学（斯密、李嘉图）和马克思主义政治经济学继承此理论。不同于效用价值论（边际革命）。劳动价值论从供给/成本侧解释价值，效用价值论从需求侧解释。
剩余价值Surplus Values马克思的术语，指工人劳动创造的价值超过其劳动力价值（工资）的部分。剩余价值率 s/v 衡量剥削程度。不同于利润。马克思认为利润是剩余价值的转化形式，利润的平均化通过利润率平均化趋势实现。
有效需求Effective DemandAD凯恩斯的概念，指有支付能力的总需求，由消费（C）、投资（I）、政府购买（G）和净出口（NX）组成。有效需求不足是失业和经济衰退的根本原因。不同于潜在需求（想买但买不起）。有效需求 = 愿意且能够购买的总量。
流动性偏好Liquidity PreferenceL凯恩斯提出的货币需求理论，认为人们持有货币的动机有三：交易动机、预防动机和投机动机。利率是放弃流动性的报酬。不同于费雪方程式（MV=PT）。流动性偏好理论强调利率作为货币供求均衡的决定变量。
边际消费倾向Marginal Propensity to ConsumeMPC可支配收入每增加一单位时消费的增加量。MPC = dC/dY，通常在0到1之间。乘数 = 1/(1-MPC)。不同于平均消费倾向（APC）。APC = C/Y，MPC是边际概念。
自然失业率Natural Rate of Unemploymentu*经济在长期中趋向的失业率，由摩擦性失业和结构性失业组成，与周期性失业相对。弗里德曼和费尔普斯首次提出。不同于实际失业率（u）。实际失业率围绕自然失业率波动，两者之差为周期性失业。
滞胀Stagflation—经济停滞（高失业、低增长）与通货膨胀同时发生的现象。1970年代石油危机期间首次出现，动摇了凯恩斯主义菲利普斯曲线的理论基础。不同于传统衰退（价格下降）。滞胀打破了"失业与通胀反向变动"的经验规律。

附录四推演方法与证明

经济思想史上的重大突破往往伴随着分析方法的革新。本附录梳理了古典经济学、边际革命和凯恩斯主义的核心论证方法，帮助读者理解"经济学如何推导出结论"。

4.1 古典经济学的演绎推理

亚当·斯密和李嘉图采用演绎推理方法：从少数几个基本假设出发，通过逻辑推导得出一般性结论。斯密的《国富论》从"自利动机"和"分工提高效率"两个前提出发，推导出"看不见的手"和自由贸易的结论。李嘉图的比较优势论证是这一方法的典范：

比较优势定理的证明

假设：两国（英/葡）、两种商品（布/酒）、一种生产要素（劳动）。

命题：即使一国在所有商品上都具有绝对优势，两国仍可通过专业化生产和贸易互利。

证明思路：

  1. 定义比较优势：一国生产某种商品的机会成本低于另一国。
  2. 如果英国生产布的机会成本（放弃的酒）低于葡萄牙，而葡萄牙生产酒的机会成本（放弃的布）低于英国，则两国分别专业化生产机会成本较低的商品。
  3. 各国在专业化后总产出增加，通过贸易按介于两国机会成本之间的价格交换，两国均获益。

结论：比较优势而非绝对优势决定贸易模式——这是经济学中少数几个"诺贝尔奖级别的非直观真理"之一（萨缪尔森语）。

4.2 边际分析方法

边际革命的核心方法论贡献是将微积分引入经济学分析。边际分析的核心思想是：所有经济决策都是"边际上"的决策——不是"做或不做"的二选一，而是"多做一点或少做一点"的边际选择。

消费者最优条件 MU1 / P1 = MU2 / P2 = ... = MUn / Pn = λ 每单位货币的边际效用相等，λ为货币的边际效用
生产者最优条件 MR = MC 边际收益等于边际成本，利润最大化的一阶条件
图 A4-1 · 边际收益(MR)与边际成本(MC)曲线。交点处为企业利润最大化的产量 Q*。当 MR > MC 时，增产可增加利润；当 MR < MC 时，减产可增加利润。

4.3 凯恩斯主义的宏观推演

凯恩斯在《就业、利息和货币通论》中建立了一种全新的宏观分析方法：从有效需求出发，通过乘数效应解释经济波动，并以流动性偏好理论取代古典货币数量论。

乘数效应 ΔY = (1 / (1 - MPC)) × ΔI = k × ΔI MPC = 边际消费倾向；k = 1/(1-MPC) = 乘数；MPC=0.8 时，k=5，即100元投资增加500元产出

凯恩斯推演的关键逻辑链：投资下降 → 总需求不足 → 企业减产裁员 → 收入下降 → 消费进一步下降 → 总需求进一步下降（乘数的反向作用）。这一"节俭悖论"——个人多储蓄是美德，全社会多储蓄导致衰退——揭示了微观理性与宏观理性之间的深刻矛盾。

批判性思考：推演方法的局限

每种推演方法都有其前提假设的局限性：

  • 古典经济学的演绎推理依赖于"理性人"假设，行为经济学证明了真实决策存在系统性偏差。
  • 边际分析假设偏好是连续的、可微的，但现实中消费决策可能是离散的（如买车、买房）。
  • 凯恩斯主义的宏观推演假设价格和工资在短期内是刚性的，这一假设在后来的新古典综合派中受到挑战。

理解方法的局限，是经济学批判性思维的第一步。

附录五核心模型与图表

本附录深入分析经济思想史上篇中的几个核心模型，包括供需均衡模型、IS-LM模型和AD-AS模型，并通过交互式图表展示其内在逻辑。

5.1 供需均衡：价格发现与福利分析

供需模型是经济学最基础的模型。在完全竞争市场中，价格由供给和需求共同决定，均衡价格使市场出清。消费者剩余和生产者剩余之和衡量市场效率。

图 A5-1 · 供需均衡与福利分析。蓝色区域：消费者剩余(CS)；橙色区域：生产者剩余(PS)。CS+PS=总剩余，在完全竞争市场中达到最大。

5.2 IS-LM 模型：商品市场与货币市场的均衡

IS-LM模型由希克斯（1937）提出，是对凯恩斯理论的经典形式化表达。IS曲线代表商品市场均衡（I=S），LM曲线代表货币市场均衡（L=M），两条曲线的交点决定均衡利率和均衡产出。

IS曲线方程 Y = C(Y - T) + I(r) + G Y = 产出, C = 消费, T = 税收, I = 投资, r = 利率, G = 政府购买
LM曲线方程 M/P = L(Y, r) M/P = 实际货币供给, L(Y, r) = 实际货币需求（取决于产出Y和利率r）
图 A5-2 · IS-LM模型。IS曲线向右下倾斜（利率下降刺激投资→产出增加），LM曲线向右上倾斜（产出增加提高货币需求→利率上升）。交点E为均衡点。

5.3 AD-AS 模型：总需求与总供给

AD-AS模型将IS-LM模型扩展到价格水平维度，分析整体经济的波动。总需求曲线（AD）向右下倾斜，短期总供给曲线（SRAS）向右上倾斜，长期总供给曲线（LRAS）垂直。需求冲击和供给冲击通过移动这些曲线导致经济波动。

图 A5-3 · AD-AS模型。绿色竖线为长期总供给(LRAS)，蓝色曲线为总需求(AD)，橙色曲线为短期总供给(SRAS)。需求冲击导致AD移动，供给冲击导致SRAS移动。

附录六高阶理论与前沿

本附录为已经掌握基础经济学知识的本科生提供通向学术前沿的桥梁。以下主题在主流经济学研究生课程中占有重要地位，但本科生可以通过系统学习提前接触。

6.1 一般均衡理论：瓦尔拉斯的天才构想

瓦尔拉斯（1874）在《纯粹经济学要义》中提出了经济学史上最具雄心的理论构想——一般均衡理论。与局部均衡（仅分析单一市场）不同，一般均衡考虑所有市场之间的相互依赖关系。

一般均衡的核心问题

是否存在一组价格 (P1, P2, ..., Pn)，使得所有市场同时达到均衡？

阿罗和德布鲁（1954）用拓扑学中的不动点定理（布劳威尔/角谷不动点定理）严格证明了在完全竞争条件下一般均衡的存在性。这一证明是经济学最伟大的理论成就之一，阿罗和德布鲁因此获得诺贝尔经济学奖。

阿罗-德布鲁模型的核心假设：

  • 完全竞争（所有参与者是价格接受者）；
  • 凸偏好（边际替代率递减）；
  • 凸生产技术（边际收益递减）；
  • 完备的市场（所有可能状态下的商品都有市场）。

两个福利定理：第一福利定理（竞争均衡是帕累托最优的）和第二福利定理（任何帕累托最优配置都可以通过竞争均衡实现，前提是适当的转移支付）构成了经济学对市场效率的正式论证。

6.2 博弈论：策略互动的数学分析

冯·诺伊曼和摩根斯坦（1944）在《博弈论与经济行为》中开创了博弈论。纳什（1950）证明了非合作博弈中纳什均衡的存在性，彻底改变了经济学对策略互动的理解。

纳什均衡 在一个 N 人博弈中，策略组合 (s1*, s2*, ..., sN*) 是纳什均衡，当且仅当对每个参与者 i：ui(si*, s-i*) ≥ ui(si, s-i*) 对所有 si ∈ Si 成立 即每个参与者的策略是对其他参与者策略的最优反应

经典博弈：囚徒困境——两个囚徒各自选择"坦白"或"沉默"，个人理性导致集体非理性（双方都坦白）。这一博弈揭示了：在缺乏合作机制的情况下，个人理性可能导致社会整体的福利损失。

6.3 信息经济学与机制设计

阿克洛夫（1970）在《柠檬市场》中揭示了信息不对称如何导致市场失灵。斯彭斯（1973）的劳动力市场信号模型和斯蒂格利茨（1976）的逆向选择与道德风险模型，共同构成了信息经济学的三大支柱。

柠檬市场模型

问题：二手车市场中，卖方知道车况，买方不知道。买方只能根据平均质量出价，导致高质量车退出市场，平均质量进一步下降，最终市场崩溃。

数学表达：假设高质量车价值 VH，低质量车价值 VL，高质量车占比 q。买方愿意支付的价格为 P = qVH + (1-q)VL。如果 VH > P，高质量车车主退出市场，q 下降，P 进一步下降——这就是"劣币驱逐良币"的逆向选择过程。

解决机制：信号传递（如质量保证）、信息中介（如第三方检测）、声誉机制、政府规制。

6.4 行为经济学的前沿

卡尼曼和特沃斯基的前景理论（1979）将心理学发现形式化，建立了描述性决策理论。塞勒（2017诺贝尔奖得主）将行为洞察应用于公共政策（助推理论）。行为经济学不是对主流经济学的否定，而是对"理性人"假设的修正和拓展。

前景理论的价值函数 v(x) = xα 当 x ≥ 0；v(x) = -λ(-x)β 当 x < 0 其中 λ > 1 为损失厌恶系数（典型值 λ ≈ 2.25），α、β ∈ (0,1) 为边际敏感度递减参数

附录七方法训练与实操指南

经济学不仅是一套理论体系，更是一套分析工具。本附录提供具体的方法训练指南，帮助本科生将理论知识转化为可操作的分析能力。

7.1 边际分析实操：从概念到计算

场景：一家面包店每天生产面包的边际成本如下：第1个面包MC=1元，第2个MC=1.5元，第3个MC=2元，第4个MC=3元，第5个MC=5元。面包售价为3元/个。

问题：该店每天应该生产多少个面包？

解法：运用利润最大化条件 MR=MC。MR=3元。当产量为3个时，MC=2元 < MR=3元，增产有利；当产量为4个时，MC=3元 = MR，这是最优产量；当产量为5个时，MC=5元 > MR=3元，减产有利。因此最优产量为4个。

7.2 弹性分析实操

场景：某商品原价10元，销量1000个。降价至8元后，销量增至1500个。

问题：(1)计算需求价格弹性。(2)判断该商品是富有弹性还是缺乏弹性。(3)降价对总收益有何影响？

解法：

(1) 中点法弹性 = [(1500-1000)/1250] / [(8-10)/9] = (0.4)/(-0.222) ≈ -1.8，取绝对值1.8。

(2) |Ed| = 1.8 > 1，富有弹性。

(3) 原总收益 = 10×1000 = 10000元；新总收益 = 8×1500 = 12000元。降价使总收益增加，验证了"富有弹性的商品降价增加总收益"的规律。

7.3 乘数分析实操

场景：假设一个经济体的MPC=0.75，政府增加基础设施投资200亿元。

问题：(1)计算乘数。(2)计算最终总产出的增加量。(3)如果MPC变为0.5，乘数如何变化？

解法：

(1) 乘数 k = 1/(1-MPC) = 1/(1-0.75) = 4。

(2) ΔY = k × ΔI = 4 × 200 = 800亿元。

(3) MPC=0.5时，k = 1/(1-0.5) = 2。MPC越小，乘数越小，财政政策效果越弱。

7.4 数据可视化与图形分析

经济分析中，图形是最重要的交流工具。建议按照以下步骤训练图形分析能力：

  1. 读图：识别坐标轴含义、曲线类型、均衡点、移动方向。
  2. 推演：分析曲线移动的原因（需求冲击还是供给冲击），追踪新均衡的形成过程。
  3. 求值：计算消费者剩余、生产者剩余、无谓损失等福利指标的变化。
  4. 解释：用文字将图形分析的结果翻译为政策含义或经济结论。
实操建议

建议每周完成2-3道图形分析题，从局部均衡开始，逐步过渡到一般均衡和宏观模型。使用Excel或在线工具绘制供需曲线、成本曲线、IS-LM曲线等，培养"手绘+计算"的双重技能。

附录八经典习题集

以下五道习题覆盖了经济思想史上篇的核心知识点，从供需分析到宏观政策，难度递进。参考答案附于每题之后。

习题一：供需分析（基础）

已知某商品的市场需求函数为 Qd = 100 - 2P，市场供给函数为 Qs = -20 + 4P。

(1) 求均衡价格和均衡数量。

(2) 如果政府设定了最低限价 Pmin = 25，会出现过剩还是短缺？数量是多少？

(3) 计算最低限价导致的消费者剩余变化和生产者剩余变化。

参考答案

(1) 令 Qd = Qs：100 - 2P = -20 + 4P → 6P = 120 → P* = 20, Q* = 100 - 40 = 60。

(2) 当 P=25时，Qd = 100 - 50 = 50，Qs = -20 + 100 = 80，过剩 = 80 - 50 = 30。

(3) 最低限价下，实际交易量为50（需求量的较小值）。CS减少，PS变化不确定（部分生产者以高价卖出，部分退出市场），存在无谓损失。

习题二：弹性分析（进阶）

某公司将其产品价格从50元降至40元，观察到销量从2000单位增至2400单位。

(1) 用中点法计算需求价格弹性。

(2) 降价前和降价后的总收益分别是多少？

(3) 根据弹性值判断，该产品是奢侈品还是必需品？说明理由。

参考答案

(1) 中点法：ΔQ/Qavg = 400/2200 ≈ 0.182，ΔP/Pavg = -10/45 ≈ -0.222，Ed = 0.182/(-0.222) ≈ -0.82，|Ed| = 0.82。

(2) 降价前 TR = 50×2000 = 100000元；降价后 TR = 40×2400 = 96000元。总收益下降。

(3) |Ed| = 0.82 < 1，缺乏弹性，属于必需品（如食品、药品等缺乏替代品的商品）。

习题三：生产理论与成本分析（综合）

一家企业的短期生产函数为 Q = 10L + 3L² - 0.1L³，其中L为劳动投入。工资率 w = 50元，固定成本 FC = 200元。

(1) 计算劳动的边际产出 MPL 函数。

(2) 当L=10时，边际产出是多少？解释其经济含义。

(3) 求该企业的短期总成本函数 STC(Q)。

参考答案

(1) MPL = dQ/dL = 10 + 6L - 0.3L²。

(2) 当L=10时，MPL = 10 + 60 - 30 = 40。经济含义：增加一单位劳动投入，产出增加40单位。

(3) 由于Q和L的关系是非线性的，无法直接得到STC(Q)的显式表达式。但概念上：STC(Q) = 50L(Q) + 200，其中L(Q)是生产函数的反函数。

习题四：IS-LM 模型分析（宏观）

假设一个经济体的消费函数为 C = 200 + 0.75(Y - T)，投资函数为 I = 150 - 25r，政府购买 G = 100，税收 T = 100。货币需求函数为 L = 0.2Y - 10r，实际货币供给 M/P = 150。

(1) 推导IS曲线方程。

(2) 推导LM曲线方程。

(3) 求解均衡产出和均衡利率。

参考答案

(1) IS: Y = C + I + G = 200 + 0.75(Y-100) + 150 - 25r + 100 = 375 + 0.75Y - 25r → 0.25Y = 375 - 25r → Y = 1500 - 100r。

(2) LM: 150 = 0.2Y - 10r → 0.2Y = 150 + 10r → Y = 750 + 50r。

(3) 联立IS和LM：1500 - 100r = 750 + 50r → 150r = 750 → r* = 5，Y* = 750 + 50×5 = 1000。

习题五：经济思想史综合（批判性思考）

比较古典经济学和凯恩斯主义关于"市场能否自动实现充分就业"的争论。

(1) 分别阐述两个学派的观点和核心论证。

(2) 指出两个学派在"工资和价格灵活性"假设上的分歧。

(3) 结合2008年全球金融危机，讨论哪一学派的观点更符合现实。

参考答案要点

(1) 古典经济学：萨伊定律"供给创造自身需求"，市场通过价格机制自动出清，不会出现长期非自愿失业。凯恩斯主义：有效需求不足导致非自愿失业，市场无法自动恢复充分就业，需要政府干预。

(2) 古典假设工资和价格完全灵活，能迅速调整到出清水平；凯恩斯假设工资和价格具有向下的刚性（尤其是名义工资），导致市场无法自动出清。

(3) 2008年金融危机后，全球失业率大幅上升，市场并未自动快速恢复，各国政府普遍采取财政和货币刺激政策——这更符合凯恩斯主义的预测。但长期来看，市场确实在恢复（尽管缓慢），体现了古典经济学"长期市场出清"的合理性。

附录十关键争论

经济思想史不仅是理论的演进史，更是争论的历史。以下五个关键争论塑造了经济学的面貌。

10.1 劳动价值论 vs 效用价值论

核心问题：商品的价值是由生产它所需的劳动量决定，还是由消费者对它的主观评价决定？

争论双方：古典—马克思阵营（劳动价值论）vs 边际革命阵营（效用价值论）。

争论要点：

  • 劳动价值论无法解释"钻石与水悖论"——钻石对人类生存几乎没有价值，但价格极高；水对人类生存至关重要，但价格极低。边际效用论用"边际效用递减"完美解释：钻石稀缺，边际效用高；水充裕，边际效用低。
  • 劳动价值论在解释非劳动产品（如土地、自然资源）的价格时遇到困难。效用价值论通过"要素定价"（土地的地租由其边际生产力决定）解决。
  • 马克思认为劳动价值论揭示了资本主义的剥削本质；边际效用论则掩盖了生产中的社会关系。

学术共识：现代经济学中，效用价值论是主流。但劳动价值论在分析收入分配、经济增长和全球化问题时仍有其解释力，尤其是在马克思主义经济学传统中。

10.2 自由市场 vs 政府干预

核心问题：市场能否自动实现资源的最优配置？政府应该在什么程度上干预经济？

争论双方：古典经济学/新自由主义（市场自由）vs 凯恩斯主义/制度学派（政府干预）。

争论要点：

  • 斯密的"看不见的手"论证了市场自发的协调功能，哈耶克（1945）进一步从"知识问题"角度论证了中央计划的不可行性。
  • 凯恩斯（1936）证明在有效需求不足时，市场无法自动恢复充分就业，政府必须通过财政和货币政策进行逆周期调节。
  • 弗里德曼（1968）的自然失业率假说挑战了凯恩斯主义长期干预的基础，认为长期中失业率由结构性因素决定，货币扩张只会导致通胀。
  • 2008年金融危机和2020年新冠疫情后，政府的积极干预（量化宽松、财政刺激、工资补贴）再次证明了凯恩斯主义政策的有效性，但也引发了关于政府债务可持续性的担忧。

10.3 货币中性 vs 货币非中性

核心问题：货币供给的变化仅影响价格水平（中性），还是也影响实际产出和就业（非中性）？

争论要点：

  • 古典二分法认为经济分为"真实部门"和"货币部门"，货币只是"面纱"，不影响真实变量。
  • 凯恩斯主义认为，在短期内，由于价格和工资刚性，货币供给变化影响实际利率和投资，从而影响总产出和就业（非中性）。
  • 理性预期学派（卢卡斯、萨金特）认为，如果货币供给变化被完全预期到，则不会影响实际产出——只有"未预期到的"货币变化才有真实效应。
  • 现代宏观经济学的主流观点是"短期非中性，长期中性"——货币在短期内影响真实变量，在长期内只影响价格水平。

10.4 边际革命：连续性还是断裂？

核心问题：边际革命（1870年代）是经济学理论的一次革命性断裂，还是古典经济学内在逻辑的延续？

争论要点：

  • 传统经济思想史叙述（如熊彼特《经济分析史》）强调边际革命的"革命性"：从客观价值论转向主观价值论，从成本分析转向边际分析，从宏观视角转向微观视角。
  • 修正主义观点（如霍兰德）认为，斯密和李嘉图已经包含了边际分析的萌芽，边际革命只是对古典传统的延续和精确化，而非断裂。
  • 马克思主义观点认为，边际革命是资产阶级意识形态对马克思劳动价值论的理论回应，试图通过将价值归结为主观效用来回避资本主义的剥削问题。

10.5 凯恩斯主义 vs 货币主义：菲利普斯曲线的命运

核心问题：失业与通胀之间是否存在稳定的替代关系？

争论要点：

  • 菲利普斯（1958）发现英国失业率与工资增长率之间存在反向关系。萨缪尔森和索洛将其推广到通胀与失业的关系，为凯恩斯主义的宏观管理提供了经验基础。
  • 弗里德曼和费尔普斯（1968）独立论证，长期中不存在通胀与失业的替代关系——失业率会回到"自然失业率"，通胀只会被完全纳入预期。这一理论在1970年代滞胀中得到验证。
  • 现代观点：短期菲利普斯曲线存在但斜率可变，长期菲利普斯曲线是垂直的。通胀预期是连接短期和长期的关键变量。

学习路径建议

对于计划考研或出国深造的本科生：

  • 大二结束前：完成曼昆《经济学原理》和范里安《微观经济学》的阅读，掌握供需分析、成本理论、市场结构等核心内容。
  • 大三：精读布兰查德《宏观经济学》和一本经济思想史教材，开始接触博弈论和信息经济学。
  • 大四：阅读本附录九推荐的一手文献，培养批判性思维。同时学习计量经济学，掌握实证研究方法。
